# Cravabala – Portfólio (VF2)

Site estático em HTML, CSS e JavaScript.

## Estrutura
```
portfolioVF2/
├── index.html
├── css/style.css
├── js/main.js        (tema, máquina de escrever, players)
├── js/ondas.js       (desenho do waveform de cada beat)
├── images/           (foto, capas e favicon)
├── audio/            (os 6 beats e a tag, em MP3)
└── media/            (clipe de fundo e imagem de capa dele)
```

## Ver no computador
No VS Code, instale a extensão Live Server, clique com o botão direito em `index.html` e escolha "Open with Live Server".

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todas as pastas e o `index.html` para a raiz do repositório.
3. Em Settings → Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)` e salve.
4. Em 1 a 2 minutos o site abre em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
